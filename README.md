\# Classificação de Notas Escolares (Bubble Sort \& Quick Sort)



\### Situação-Problema e Objetivo

Ao final do semestre, professores precisam organizar as notas de seus alunos para identificar rapidamente o desempenho geral da turma, separar aprovados de reprovados e gerar boletins. O objetivo desta aplicação é receber 10 notas desorganizadas e ordená-las de forma crescente utilizando dois métodos de ordenação diferentes para fins de comparação.



\### Como funcionam os Algoritmos?

\* \*\*Bubble Sort:\*\* Um algoritmo simples que percorre a lista várias vezes, comparando pares de elementos vizinhos e trocando-os de lugar se estiverem na ordem errada. É fácil de implementar, mas ineficiente para listas grandes.

\* \*\*Quick Sort:\*\* Um algoritmo avançado de divisão e conquista. Ele escolhe um elemento como "pivô" e separa a lista em duas partes: os menores que o pivô à esquerda e os maiores à direita. Ele repete esse processo recursivamente, sendo muito mais rápido e eficiente para grandes volumes de dados.
